# Use the organizer client and Realtime Database as the hackathon authority

CodexWars stores each War Room's live projection and append-only Battle Events in Firebase Realtime Database so organizer and participant clients receive one synchronized flow across lobby, quiz, arena readiness, battle, and results. For the hackathon there is no separate application backend: participants may write only their own presence, answers, character/position updates, and attack requests, while the organizer client owns phase transitions and uses RTDB transactions to atomically write Attack Resolutions, Battle Stats, eliminations, rankings, and Battle Events. This deliberately trades anti-cheat protection and organizer-failure resilience for delivery speed; the pure resolver and database interface remain reusable if authority later moves to Cloud Functions or a Node process.
